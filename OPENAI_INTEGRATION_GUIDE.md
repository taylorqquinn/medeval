## Overview

MedEval supports **two modes** for LLM operations:

1. **Test Mode** (default) - Uses deterministic fallback heuristics, no API calls
2. **Production Mode** - Makes real OpenAI API calls with cost tracking and rate limiting

### Features

✅ **Real API Integration** - Connects to OpenAI's GPT models  
✅ **Cost Tracking** - Monitors token usage and calculates costs  
✅ **Budget Enforcement** - Prevents overspending with configurable limits  
✅ **Rate Limiting** - Avoids quota exhaustion with automatic throttling  
✅ **Model Flexibility** - Supports GPT-4, GPT-3.5-turbo, and more  
✅ **Automatic Fallback** - Gracefully handles API failures

## Quick Start

### 1. Install OpenAI Package

```bash
pip install openai>=1.0.0
```

### 2. Set API Key

**Option A: Environment Variable (Recommended)**
```bash
# Windows PowerShell
$env:OPENAI_API_KEY="sk-your-api-key-here"

# Linux/Mac
export OPENAI_API_KEY="sk-your-api-key-here"
```

**Option B: Configuration File** (not recommended for security)
```yaml
# medeval_config.yaml
llm:
  openai:
    api_key_source: "file"
    api_key_file: "C:/path/to/api_key.txt"
```

### 3. Enable OpenAI Client

**Edit `medeval_config.yaml`:**
```yaml
llm:
  client_type: "openai"  # Change from "deterministic" to "openai"
```

### 4. Run Evaluation

```bash
python -m medeval run --dataset datasets/clinical_cases.jsonl --mode standard
```

### 5. Check Cost Report

After the run completes:
```bash
python -m medeval report --run <run_id>
# Or check: .logs/medeval_<timestamp>/artifacts/cost_report.json
```

## Configuration

### Full Configuration Options

```yaml
llm:
  # Client type: 'deterministic' (test mode) or 'openai' (production mode)
  client_type: "openai"
  
  openai:
    # API Key Configuration
    api_key_source: "env"  # Options: 'env', 'file', 'inline'
    api_key_file: null     # Path to file containing API key
    api_key: null          # Inline key (NOT RECOMMENDED)
    
    # Model Selection
    model: "gpt-3.5-turbo"        # Main model for generation
    judge_model: "gpt-4o-mini"    # Optional separate model for judging
    
    # Generation Settings
    temperature: 0.0      # 0.0 = deterministic, higher = more creative
    max_tokens: 256       # Max tokens for clinical summaries
    judge_max_tokens: 8   # Max tokens for judge scores
    
    # Optional: Organization ID for team/enterprise accounts
    organization: null
    
    # Rate Limiting
    rate_limit:
      enabled: true
      max_requests_per_minute: 60
      max_tokens_per_minute: 90000
      min_delay_seconds: 1.0
    
    # Cost Tracking & Budget
    cost_tracking:
      enabled: true
      max_cost_per_run: 1.0     # Max $1 per evaluation run
      max_cost_per_case: 0.05   # Max $0.05 per clinical case
      save_cost_report: true
      
      # Pricing (update these based on current OpenAI pricing)
      pricing:
        gpt-4:
          input: 0.03   # per 1K tokens
          output: 0.06
        gpt-4-turbo:
          input: 0.01
          output: 0.03
        gpt-3.5-turbo:
          input: 0.0005
          output: 0.0015
        gpt-4o:
          input: 0.005
          output: 0.015
        gpt-4o-mini:
          input: 0.00015
          output: 0.0006
    
    # Retry Settings
    retry:
      max_attempts: 3
      backoff_seconds: 2
      exponential_backoff: true
      retry_on_errors: ["RateLimitError", "APIError", "Timeout"]
```

## Cost Tracking

### How It Works

MedEval automatically tracks:
- **Input tokens** - Prompt and context sent to API
- **Output tokens** - Response generated by API
- **Total cost** - Calculated using current pricing
- **Per-operation breakdown** - Separate costs for generation vs. judging

### Cost Report Format

```json
{
  "total_cost_usd": 0.012345,
  "total_requests": 16,
  "total_input_tokens": 4520,
  "total_output_tokens": 1280,
  "total_tokens": 5800,
  "cost_per_request": 0.000772,
  "cost_by_operation": {
    "generate": 0.008123,
    "judge": 0.004222
  },
  "requests_by_operation": {
    "generate": 8,
    "judge": 8
  }
}
```

### Budget Enforcement

**Per-Run Budget:**
```yaml
cost_tracking:
  max_cost_per_run: 1.0  # Stop if total cost exceeds $1
```

**Per-Case Budget:**
```yaml
cost_tracking:
  max_cost_per_case: 0.05  # Stop if single case exceeds $0.05
```

When budget is exceeded, you'll see:
```
RuntimeError: Budget exceeded: generate would cost $1.05, max is $1.00
```

### Viewing Cost Reports

**Via CLI:**
```bash
python -m medeval report --run 20260828_162214
```

**Via JSON file:**
```bash
cat .logs/medeval_20260828_162214/artifacts/cost_report.json
```

**During Evaluation:**
Check the logs for real-time cost updates:
```
[2026-08-28 16:22:14] medeval.openai_client - INFO - Total API cost: $0.012345
```

## Rate Limiting

### Why Rate Limiting?

OpenAI enforces API quotas:
- **Free tier**: 3 requests/minute, 40K tokens/minute
- **Pay-as-you-go**: 3500 requests/minute, 90K tokens/minute (GPT-3.5)
- **Pay-as-you-go**: 500 requests/minute, 10K tokens/minute (GPT-4)

MedEval's rate limiter **prevents quota exhaustion** by:
1. Tracking requests per minute
2. Tracking tokens per minute
3. Enforcing minimum delay between requests
4. Automatically sleeping when limits approached

### Configuration

```yaml
rate_limit:
  enabled: true
  max_requests_per_minute: 60          # Adjust based on your tier
  max_tokens_per_minute: 90000         # GPT-3.5 pay-as-you-go limit
  min_delay_seconds: 1.0               # Minimum 1s between requests
```

### Rate Limit Behavior

When rate limit is approached:
```
[2026-08-28 16:22:14] medeval.openai_client - WARNING - Rate limit: 60 req/min reached. Waiting 5.2s
[2026-08-28 16:22:19] medeval.openai_client - DEBUG - Rate limiting: sleeping 0.5s for min delay
```

**Tip:** For large datasets, use a smaller `max_requests_per_minute` to stay well under limits.

python -m medeval list-runs --limit 5

from medeval.application.openai_client import OpenAIClient

# GPT-3.5-turbo
client_35 = OpenAIClient(model="gpt-3.5-turbo")

## Best Practices

### 1. Start with Test Mode

Before using real API:
```yaml
llm:
  client_type: "deterministic"  # Test your pipeline first
```

Run a full evaluation to verify everything works.

### 2. Use Small Budgets Initially

```yaml
cost_tracking:
  max_cost_per_run: 0.10  # Start with $0.10 limit
```

Gradually increase once confident.

### 3. Monitor Costs in Real-Time

Watch the logs during evaluation:
```bash
python -m medeval run --dataset datasets/clinical_cases.jsonl --mode debug
```

### 4. Choose Appropriate Models

- **Development/Testing**: gpt-3.5-turbo
- **Production**: gpt-4o or gpt-4-turbo
- **Judging**: gpt-4o-mini (cheaper, sufficient for scoring)

### 5. Set Rate Limits Conservatively

```yaml
rate_limit:
  max_requests_per_minute: 30  # Half of your tier limit
```

Provides buffer for other API usage.

### 6. Secure API Keys

**Never commit API keys to git!**

Use environment variables:
```bash
# Add to .gitignore
echo "*.env" >> .gitignore
echo "api_key*.txt" >> .gitignore
```

### 7. Archive Cost Reports

```bash
# Copy cost reports to a tracking folder
mkdir cost_analysis
cp .logs/*/artifacts/cost_report.json cost_analysis/
```

## Troubleshooting

### Issue: "No OpenAI API key found"

**Solution:**
```bash
# Check environment variable
echo $env:OPENAI_API_KEY  # Windows
echo $OPENAI_API_KEY      # Linux/Mac

# If empty, set it
$env:OPENAI_API_KEY="sk-your-key-here"
```

### Issue: "RateLimitError"

**Solution 1: Increase rate limit delay**
```yaml
rate_limit:
  min_delay_seconds: 2.0  # Increase from 1.0
```

**Solution 2: Reduce requests per minute**
```yaml
rate_limit:
  max_requests_per_minute: 20  # Reduce from 60
```

### Issue: "Budget exceeded"

**Solution: Increase budget**
```yaml
cost_tracking:
  max_cost_per_run: 2.0  # Increase from 1.0
```

Or use cheaper model:
```yaml
openai:
  model: "gpt-3.5-turbo"  # Change from gpt-4
```

### Issue: API calls not being made (fallback used)

**Check:**
1. Is `client_type` set to `"openai"`?
2. Is API key set correctly?
3. Is `openai` package installed?

**Debug:**
```bash
python -c "import openai; print(openai.__version__)"
python -c "import os; print('Key:', os.getenv('OPENAI_API_KEY')[:10]+'...')"
```

### Issue: Costs don't match expectations

**Solution: Update pricing in config**

Check current pricing at https://openai.com/api/pricing/

```yaml
cost_tracking:
  pricing:
    gpt-4o:
      input: 0.005   # Update to current rate
      output: 0.015  # Update to current rate
```
